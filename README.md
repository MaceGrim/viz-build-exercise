# Viz Build Exercise

Welcome! This is a small, self-contained exercise built on real public data. Everything
you need is in this repo.

## Setup (do this first)

```bash
python3 -m venv .venv && source .venv/bin/activate   # or conda/uv, your call
pip install -r requirements.txt
```

QGIS is welcome too if that's part of your toolkit — optional, not required.

## Then

1. Read `BRIEF.md` — the task.
2. Skim `STYLE.md` — the publication's design guide.
3. Check `data/`, `report/`, and `SOURCES.json` — the materials and where they come from.

Work however you normally would, AI tools included. Talk through what you're doing as you go.
